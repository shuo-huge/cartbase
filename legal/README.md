# Legal documents

This directory currently contains the Contributor License Agreement used for pull
requests. The commercial license template is kept outside the public repository until the
project starts offering commercial terms.

> **These are templates, not legal advice.** Have qualified counsel in your jurisdiction
> review them and complete every placeholder before you rely on them.

## Files

| File | Purpose |
|---|---|
| [`CLA.md`](CLA.md) | Contributor License Agreement. Every contributor must accept it before a pull request can be merged. It lets the project distribute contributions under MIT and keeps future commercial licensing possible. |
| [`zh-CN/CLA.md`](zh-CN/CLA.md) | Simplified Chinese reference translation of the CLA. The English text controls. |

## Placeholders to complete

Before publishing the CLA, replace all bracketed fields:

- `[LICENSOR LEGAL NAME]`, `[JURISDICTION]`, `[VENUE]`
- `[EFFECTIVE DATE]`
- `[CONTACT EMAIL]`

Use the same legal entity consistently in the CLA and any future commercial agreement. If
the project is not incorporated yet, ask counsel how to hold the rights.

## CLA workflow

1. Publish `CLA.md` and link it from `CONTRIBUTING.md` and the pull-request template.
2. Require acceptance before merge. The usual options are a CLA-check GitHub App, a signed
   PDF kept in a private records directory, or an explicit acceptance comment on the pull
   request.
3. For contributions made during employment, require a Corporate CLA signed by the
   employer.
4. Keep a dated record of every acceptance.
5. If a contribution was merged before the CLA existed, ask that contributor to confirm
   the CLA retroactively for their past contributions.

The CLA grants a broad copyright license, including the right to relicense under
proprietary terms. A DCO sign-off alone is **not** sufficient if the project later offers
commercial terms.

## Commercial licensing

There is no commercial license on offer yet. Keep the draft agreement and pricing notes
outside this public repository (for example, in a private repository or the local
`business/` directory). Revisit the commercial model only after the project has traction
and after the CLA records are complete.
